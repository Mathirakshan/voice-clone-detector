# VoiceGuard AI - Frontend UI

This is the React + Vite frontend for **VoiceGuard AI (Voice Clone & Deepfake Audio Detector)**.

For full project details, backend integration, model setup, and full installation instructions, please refer to the [Root README.md](../README.md).

## Quick Start (Frontend Only)

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```
